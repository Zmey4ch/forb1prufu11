# DTZ B1 — тренажёр

Сайт для подготовки к экзамену «Deutsch-Test für Zuwanderer» (DTZ, уровень B1).

**Что есть:** движок спряжения (283 глагола + правила для любых слабых), глаголы, порядок слов, падежи, связки, окончания прилагательных, лексика по темам, Hören (19 заданий + диктант), Lesen (10 текстов), Schreiben (10 писем), Sprechen 1–3 (11 картинок, 7 тем для диалога) и смешанный тест на время.

## Как выложить на GitHub Pages

1. Создайте на GitHub новый **публичный** репозиторий, например `dtz-b1`.
2. Нажмите **Add file → Upload files** и перетащите все файлы из архива: `index.html`, `app.js`, `data.js`, `data2.js`, `verbs.js`, `scenes.js`, `generate_audio.py`, `README.md` (и папку `audio`, если вы её сделали — см. ниже). Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Source: Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/dtz-b1/`. Эту ссылку можно отправить друзьям.

## Что работает без настроек

- Все тесты и автоматическая проверка: грамматика, лексика, Hören, Lesen, диктант, смешанный тест.
- Все формы любого глагола и проверка своей формы — прямо в браузере, без интернета.
- Проверка грамматики письма и устных ответов через бесплатный сервис [LanguageTool](https://languagetool.org) — без ключа (до ~20 проверок в минуту).
- Быстрая проверка письма и устных ответов: объём, обращение и прощание, Sie/du, все ли пункты раскрыты, связки.
- Озвучка через голос браузера. Лучше всего в Chrome или Edge, на телефоне голоса бывают другие.
- Микрофон (надиктовать ответ) в Chrome и Edge.

## Озвучка голосами Silero (необязательно, но звучит гораздо лучше)

Silero работает на Python, поэтому файлы озвучки нужно один раз сделать на своём компьютере:

```
pip install torch soundfile pydub
python generate_audio.py
```

(`pydub` и программа ffmpeg нужны только для MP3; без них будут WAV-файлы, они крупнее.) Скрипт озвучит все тексты Hören, диктанта и лексики (около 170 файлов) разными голосами и создаст папку `audio/`. Загрузите её на GitHub рядом с `index.html`. Сайт сам начнёт использовать эти файлы, а где файла нет, говорит голос браузера. Если поменяете тексты, запустите скрипт ещё раз: он озвучит только новые.

## Полная проверка ИИ (необязательно)

Оценка по критериям DTZ, разбор ошибок на русском и диалог с ИИ-партнёром работают через API Anthropic:

1. Получите ключ на <https://console.anthropic.com/>. Это платно: каждая проверка стоит несколько центов.
2. На сайте откройте **Настройки**, вставьте ключ и нажмите «Сохранить и проверить».

Ключ хранится **только в вашем браузере**. **Никогда не вставляйте ключ в файлы и не загружайте его на GitHub**: его сразу украдут. Каждый друг вводит свой ключ.

Прогресс тоже сохраняется только в браузере каждого человека.
